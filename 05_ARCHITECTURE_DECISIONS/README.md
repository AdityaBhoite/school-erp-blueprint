# 05 — Architecture Decisions

*Status: placeholder — no ADRs yet.*

This folder collects **Architecture Decision Records (ADRs)** accumulated across all stages of the project.

An ADR captures a single significant decision: its context, the options considered, the choice made, and the consequences. ADRs will be added as real decisions are taken (for example: multi-tenancy model, authorization enforcement strategy, data-isolation approach, technology stack).

Suggested file naming when records begin: `ADR-0001-short-title.md`, `ADR-0002-short-title.md`, …

No decisions are recorded yet — this folder intentionally starts empty of content so that ADRs reflect real, agreed choices rather than assumptions.
