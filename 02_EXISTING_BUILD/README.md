This folder is reserved for **Stage 2** of the project: an independent analysis of the existing in-house ERP build.

- Architecture (services, boundaries, deployment model).
- Functionality and feature coverage.
- Database and data model.
- Frontend (framework, structure, state management, UX).
- Backend (framework, APIs, authentication, background jobs).
- UX and usability.
- Known limitations and technical debt.

Nothing here is assumed or pre-written — the analysis will stand on the existing build's own code and evidence.
